Introduction

This gallery supports Workshop 2: Contemporary Tools Research. Use it to collect examples of art, design, and technical projects from the last 12 months that seemed impossible recently and are now being made, shared, forked, or remixed.

Each example should help the class ask better questions about agents, AI coding tools, open-source practice, and experimental interactions for phones.
