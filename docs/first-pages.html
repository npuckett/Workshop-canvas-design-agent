03 First Pages

This page walks through the first starter prompts in 01_getting_started. The goal is to generate one simple Canvas page, then change one thing at a time so you can see how the prompt structure affects the output.

01

Before Starting

Make sure you have gone through 01 Setup and 02 Basic Workflow.

This guide uses the same web-based chat workflow: choose a quick-response model, upload SKILL.md, paste a Markdown prompt, then move the generated HTML into Canvas.

If any step feels too compressed here, go back to the Basic Workflow page for the slower version with screenshots.

02

Understanding the Markdown Files

In the example files, open the 01_getting_started folder. It contains three starter prompts:

00-no-style-class-page.md

This is the base file. It gives the agent course content and page goals, but does not request a specific visual style.

01-single-style-class-page.md

This version adds one whole-page style input at the top: Style: S01 Clean Modern. Change that single line to test another theme.

02-section-style-class-page.md

This version uses multiple section-level element tags. It gives you more specific control over headers, images, lists, callouts, links, and other page parts.

The Markdown files are where you input course content, describe the basic page structure, and tag sections with visual elements from the Elements catalog.

03

Your First Generated Canvas Page

  1. Open a new Copilot Chat session and make sure the correct quick-response model is selected.
  2. Upload SKILL.md to the chat.
  3. Open 01_getting_started/01-single-style-class-page.md in VS Code.
  4. Copy and paste the full contents of that file into the chat.
  5. Press enter to generate the Canvas HTML.
  6. Download the generated code or copy it from the code block into a new file in VS Code.
  7. Create a new Canvas page and paste the HTML into the Canvas HTML editor.

The first generated page should be simple, readable, and close to the source content. That is good. This first pass is about seeing the workflow work.

04

Next Steps

  • Change the single style line in 01-single-style-class-page.md.
  • Try one of the styles listed in the Markdown comment below that line.
  • Run the same prompt again.
  • Compare the new output with the first version.

At this stage, do not change everything at once. Change one style tag, generate the page, and look at what moved.

05

A Few More Controls

  • Open 01_getting_started/02-section-style-class-page.md.
  • Follow the same generate, download, and copy-paste workflow.
  • Use the Elements catalog to look up other styles and elements that can be applied to the text.
  • Try changing a section element, such as the header, quick info block, current project callout, checklist, or button links.
  • See how different the page can become without changing the course content.
06

Important Note

Once SKILL.md is uploaded to the chat, you can ask the agent questions about the skill and how to use it.

For example, ask what a style tag means, what element would work best for a schedule, or why Canvas needs raw HTML source instead of a rendered preview.
