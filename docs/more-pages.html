04 More Pages

This page moves from the three starter prompts into the larger set in 02_simple_prompts. Each file is still copy/paste friendly, but the pages are a little more realistic: assignments, timelines, galleries, homepages, project briefs, and syllabi.

Use these as recipes. Change one tag or one content section at a time, generate again, and compare the result.

01

What These Prompts Are For

The files in 02_simple_prompts use the same pattern you saw earlier: output instructions at the top, global style tags, section-level element tags, comments with alternatives, and course content below.

assignment-page.md

A student-facing assignment brief with requirements, submission details, and a rubric.

class-page.md

A compact class session page for one meeting, including reminders and before-next-class work.

course-timeline.md

A semester schedule organized by units, key dates, progress, and grading.

gallery-page.md

A visual research prompt page with image treatment, gallery cards, and resources.

homepage.md

A course landing page with a welcome message, this-week block, links, dates, and deliverables.

project-brief.md

A larger project page with milestones, deliverables, testing norms, and submission links.

simple-syllabus.md

A condensed syllabus page with course info, schedule, grading, and workshop norms.

02

Assignment Page

02_simple_prompts/assignment-page.md creates a Canvas assignment page for Workshop 2. It is useful when students need a clean brief with purpose, requirements, research focus, submission instructions, and an evaluation rubric.

Ways to change it

  • Change the global style from S06 Editorial to S01 Clean Modern or S02 Bold Academic.
  • Try a different rubric display, such as D04 Captioned Table or separate C03 Info Card sections.
  • Change the requirements from C07 Checklist to a standard unordered list if the checklist feels too task-like.
  • Keep the due date, weight, and submission details visible; those should not be hidden in a collapsible.
03

Class Page

02_simple_prompts/class-page.md builds a minimal page for one class meeting. It is a good everyday template for agenda, reminder, reading, checklist, and resource links.

Ways to change it

  • Switch the page style to S03 Warm Minimal, S07 Studio Light, or S04 High Contrast.
  • Change the reminder from an alert box to a left-border accent if the page feels too urgent.
  • Try the agenda as a checklist, schedule grid, or info card to compare pacing.
  • Use button links only for links students need to click quickly.
04

Course Timeline

02_simple_prompts/course-timeline.md turns semester data into a readable schedule page. It includes custom colors, key dates, unit sections, schedule grids, a table of contents, and grading bars.

Ways to change it

  • Change D05 Schedule Grid to D01 Data Table for a more compact schedule.
  • Try C01 Collapsible Section if each unit has a lot of detail, but keep major deadlines visible.
  • Change the primary and accent colors to match a department or course palette.
  • Remove the progress bar once the course is not being taught week by week.
05

Gallery Page

02_simple_prompts/gallery-page.md creates a visual research page. It uses a strong theme, a linked banner image, gallery prompt cards, a deadline reminder, and resource links.

Ways to change it

  • Compare S05 Studio Dark with S07 Studio Light using the same content.
  • Swap the banner from E03 Linked Image to E01 GitHub-Hosted Image if it should not link out.
  • Change gallery prompt cards into a table if students need to compare examples side by side.
  • Keep all image URLs absolute so the page works inside Canvas.
06

Course Homepage

02_simple_prompts/homepage.md creates a practical Canvas homepage. It introduces the course, shows an image, highlights the current week, provides quick links, and lists units, dates, projects, and deliverables.

Ways to change it

  • Try S01 Clean Modern or S06 Editorial if the warm theme feels too soft for the course.
  • Move this week's work higher or lower by changing the section order in the Markdown.
  • Change the key dates from a schedule grid to info cards if there are only a few deadlines.
  • Use a real Canvas image URL or approved external image URL before pasting into Canvas.
07

Project Brief

02_simple_prompts/project-brief.md creates a full project page for the main phone interaction project. It includes a sidebar-style quick facts area, project description, objectives, milestones, deliverables, testing norms, rubric notes, and submission links.

Ways to change it

  • Switch the layout from L04 CSS Grid to L05 Centered Container if the page needs to be simpler.
  • Use D05 Schedule Grid instead of D01 Data Table for milestones that map to class weeks.
  • Keep milestone weights and submission instructions visible near the top or bottom.
  • Use collapsibles for supplemental technical notes, not for essential deadlines.
08

Simple Syllabus

02_simple_prompts/simple-syllabus.md generates a readable one-page syllabus overview. It is intentionally condensed: course info, course description, learning goals, schedule, grading, dates, and norms.

Ways to change it

  • Try S04 High Contrast for maximum readability or S06 Editorial for a plainer typographic syllabus.
  • Change the schedule density tag if the table feels too compressed.
  • Use collapsibles only for long supplemental policies, not important course norms.
  • Keep grading and major deadlines visible without requiring extra clicks.
